# Paradise Nursery Shopping Application

An e-commerce React application for Paradise Nursery, enabling users to browse a variety of house plants, view details, add items to a shopping cart, and manage their selected plants.

## Features
- Interactive landing page with background imagery and company description.
- Product listing page categorized with plant details and prices.
- Redux Toolkit state management for adding, removing, and updating cart items.
- Dynamic cart count badge and dynamic total cost calculation.

## Tech Stack
- React.js
- Redux Toolkit
- Vite / CSS3
